## 🧪 Testing Checklist & Features

1. **Scoping Verification**:
   - Log in as `colony-vk@civicpulse.app` → Notice you only see content for Vasant Kunj Colony & Sectors A/B.
   - Log in as `city@civicpulse.app` → Notice you see issues, discussions, and analytics for all colonies and localities.
2. **Issue Resolution**:
   - Log in as an official → Open any issue → Use the status workflow buttons (`Under Review` → `Approve` → `Implemented`).
3. **Polls**:
   - Officials can create polls via the **+ Create Poll** button.
   - Citizens can vote on polls (Officials are restricted with a 403 banner).
4. **Discussions**:
   - Officials/Moderators can **Lock / Unlock** discussions using the header toggle button.
5. **Profile Tab**:
   - Visit `/profile` for any user to see their administrative hierarchy chain and jurisdiction assignments.
